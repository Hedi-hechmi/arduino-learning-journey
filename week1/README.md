# Week 1 – Digital Output & Basic Embedded Control

## 📌 Overview
Week 1 focuses on understanding fundamental digital output control using Arduino. The objective was to move beyond simply “making LEDs blink” and start thinking in terms of structured embedded programming.

This week introduces timing control, modular code organization, and basic hardware interaction.

---

## 🧠 Concepts Covered
- Digital HIGH (~5V) and LOW (~0V)
- Output pin configuration using `pinMode()`
- Timing control using `delay()`
- Blocking vs sequential execution
- Modular programming using functions
- Basic circuit documentation

---

A simple blinking project using the Arduino’s built-in LED.

**Key Concepts:**

### 2️⃣ LED Pattern (External LED)

An external LED connected to digital pin 8 executes multiple blinking patterns using modular functions.

Patterns implemented:
- Single blink
- Triple flash
- Long ON state

**Key Concepts:**
- Function-based code structure
- Parameterized timing
- Loop-based repetition
- Sequential execution design

Folder:
LED_pattern/
